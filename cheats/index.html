Cheats

Dispatches debug cheat commands. Only active when Django DEBUG=True.

Expected message shape

{ "type": "Cheat", "cheat": "", ...cheat-specific fields }

Supported cheats

MockDice Force the next dice roll to specific values. { "cheat": "MockDice", "dice1": 3, "dice2": 4, "dice_bus": 5 }

Teleport Move any player to any square immediately. { "cheat": "Teleport", "player_id": 7, "square_id": 12 }

SetMoney Set a player's money to an exact amount (can be negative for testing liquidation). { "cheat": "SetMoney", "player_id": 7, "amount": 5000 }

CreateProperty Create a PropertyRelationship — give a player ownership of any square. { "cheat": "CreateProperty", "player_id": 7, "square_id": 15, "houses": 0, "mortgage": false }

DeleteProperty Delete a PropertyRelationship — strip ownership of a square from whoever holds it. { "cheat": "DeleteProperty", "square_id": 15 }
